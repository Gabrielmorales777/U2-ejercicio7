# U2-ejercicio7

### Gestión de Pedidos en un Restaurante

Este ejercicio modela la comunicación entre los objetos `Mozo` y `Cocina` mediante el envío de mensajes que transportan objetos complejos de tipo `Pedido`. Cada pedido contiene una lista de platos con sus respectivos nombres, precios y tiempos de preparación, además del número de mesa. La cocina registra las comandas recibidas en una cola de pedidos pendientes, simulando el flujo de trabajo de un restaurante y aplicando los principios de colaboración entre objetos en Java.
